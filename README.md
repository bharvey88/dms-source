# DMS Source

An **unofficial, open-source rebuild** of the [Dallas Makerspace](https://dallasmakerspace.org/)
knowledge base, built with [Astro](https://astro.build) + [Starlight](https://starlight.astro.build).

**Live site:** https://bharvey88.github.io/dms-source/

It merges both existing DMS wikis into one fast, searchable, Markdown-based site:

| Source | Platform | Migrated |
|---|---|---|
| [DMS Source](https://source.dallasmakerspace.org/) (current wiki) | Atlassian Confluence | 1,082 pages across 33 committee/SIG spaces |
| [Legacy wiki](https://dallasmakerspace.org/wiki/Main_Page) | MediaWiki 1.30 | 1,675 articles, preserved under [Legacy Wiki Archive](https://bharvey88.github.io/dms-source/archive/) |

Why: Confluence is proprietary and the legacy wiki is end-of-life. Markdown in a
public Git repo means no lock-in, real review workflow, instant full-text search
(Pagefind), and free hosting on GitHub Pages.

> This project is not affiliated with or endorsed by Dallas Makerspace.

## Layout

```
src/content/docs/<space>/…    one folder per Confluence space, page tree mirrored
src/content/docs/archive/…    legacy MediaWiki articles, grouped by category
public/files/…                migrated images & attachments (web-recompressed)
scripts/                      the full migration pipeline (see below)
migration/                    manifests produced by the pipeline (raw exports are gitignored)
```

Every migrated page keeps frontmatter provenance: `sourceUrl` (rendered as a
footer note), and archive pages carry an "archived" banner.

## Developing

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

Deploys to GitHub Pages automatically on push to `main`
(`.github/workflows/deploy.yml`).

## Re-running the migration

The site content is fully generated by the pipeline in `scripts/` — each step is
resumable and idempotent:

```bash
node scripts/export-confluence.mjs    # fetch all Confluence pages -> migration/confluence/raw/
node scripts/export-mediawiki.mjs     # fetch all legacy wiki articles -> migration/mediawiki/raw/
node scripts/convert-confluence.mjs   # raw -> src/content/docs/<space>/
node scripts/convert-mediawiki.mjs    # raw -> src/content/docs/archive/
node scripts/download-assets.mjs      # fetch every referenced image/attachment -> public/files/
node scripts/compress-images.mjs      # recompress images for the web (in place)
```

Requires Node 20+ and [pandoc](https://pandoc.org/).
