So you are having an issue with our Laser machines? \#1. Please read through the Support & FAQs pages.  We are all very busy and this is designed to be self service to the extent it can be. So save us all some time for if the answer has already been documented in the Support & FAQs section, the only reply to your question that will be offered will be a link to the Support & FAQs page.  If is truly isn't in the support page, we will add it to the page and send you a link to that information.  It is truly madness to continue answering the same question multiple times due to poor documentation.  Thanks for understanding.



All Laser Issues are to be reported on Talk using the Issues & Request process.  We have outlined the process below.  If you find it convoluted or lacking, please let us know so we can make adjustments.
