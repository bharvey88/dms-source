The motor is currently wired for low-voltage operation (T1+T7, T2+T8, T3+T9, T6+T5+T4). This will allow the motor to run off of 200V-230V.

## Winding Details

<img src="https://acim.nidec.com/motors/usmotors/-/media/Project/Nidec/USMotors-Site/Images/ProFactsImages/105-1a.gif" draggable="false" width="600" />

Speed: Single

Phase: 3\
Typical Voltage: Dual 230/460\
Winding: Star Y

**Note:** Commonly supplied on smaller HP units from approximately 326T frames and smaller.

This is based on the wiring diagram from U.S Motors <http://www.usmotors.com/TechDocs/ProFacts/Typical-3ph-Connections/Star-Y.aspx>
