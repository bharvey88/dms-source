The machine shop has several lathes ranging from full size manual lathes (Clausing-Colchester and SHARK 16x40 w/DRO,) a small CNC lathe (Tormach 8L,) and Sherline Micro lathes, both manual and CNC.

All machine shop lathes require training or checkout to authorize use.
