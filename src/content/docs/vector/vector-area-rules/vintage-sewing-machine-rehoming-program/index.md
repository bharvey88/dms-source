Current Location: Bay 1

## Intent:

Vector has received many antique sewing machines as donations. Many work or could work with simple repairs. The intention is to teach recipients that need a sewing machine to fix them, and to use them, so these strong, useful machines may go on to help others.

## Program:

1.  Where: Vector will Log each machine donated, stored in designated space.
2.  Requirements:
    1.  Machine must be available
    2.  Recipient must pay for any needed parts.
    3.  Only one machine per household.
    4.  Recipient must fix and/or maintain the machine w/ help of Vector
    5.  Repairs are functional, not cosmetic.
    6.  Recipient must complete one sewing project with the machine before they may take it home.
    7.  Recipients may not sell finished machines
        1.  Recipient may give away to another sewist in need
        2.  Recipient may donate back to DMS/Vector for another sewist in need.
    8.  Machine must be certified as complete by Vector chair or Sewing Rehoming Program Leader- before it may leave Vector.
    9.  Current DMS Board members, Current Officers, and Current Committee Chairs may not receive a machine through this program.

## Process:

1.  1.  If donor machines are available
    2.  Individuals may request a sewing machine: Verbally, or in Writing
    3.  Individual's name will be assigned to log of donated machines
    4.  Individual must request tutoring or class to learn to repair and use machine
    5.  Vector Project Rules apply.
    6.  Requested machines that become 'abandoned' will be returned to the donor pool.\
