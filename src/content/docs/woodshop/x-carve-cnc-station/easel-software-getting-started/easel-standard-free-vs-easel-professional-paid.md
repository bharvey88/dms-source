Easel software comes in two versions.  The Free version which is feature packed, along with a Professional version that contains even more features.  The software features seem to be bifurcated along the lines of features that would be required to run a sign business with the software.  You will find the cost to be so low that it shouldn't be a barrier if you wish to take advantage of the additional features.  Please keep in mind that some very smart people are writing this software and have personal expenses in life like everyone else.  If you want to spend the effort(lots of hours) to save a few dollars you can use the free VCarve license your membership entitles you to.  VCarve is a professional CNC design & CAM software package and has a significant learning curve. As noted at the bottom of the ([What is Easel](/dms-source/woodshop/x-carve-cnc-station/easel-software-getting-started/what-is-easel/)) page, we **DO NOT** provide support for this path due to the sheer magnitude of users.
