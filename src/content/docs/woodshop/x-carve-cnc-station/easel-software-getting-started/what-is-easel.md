*From the vendors website:*

**Easel Pro is the World's Easiest CAD/CAM Software**\
An all-in-one CNC software solution for your business so you can start carving in minutes.



 Easel is a software package that runs inside your web browser that it used to create designs and cut them on our X-Carve CNC machine.  It is similar to any other vector drawing package.  Not unlike the software package Lightburn that is being used to control our Laser Cutter machines.



There are two aspects to the software. The first being providing the drawing tools used to create your design(SVG and STL files may be imported), and the control software that actually runs the X-Carve CNC machine while your design is being cut.

A great feature of Easel is the real time preview of what your design will look like when cut.

**Note:** Other software can be used to control the X-Carve machine via it's .  Since are supporting hundreds of users we **DO NOT** provide any support for other software packages.  You can visit the X-Carve forum & help desk for more details(<https://inventables.zendesk.com/hc/en-us/articles/360012726314-Grbl-Overview-and-FAQ>). The reality is that if you can use VCarve, Fusion 360, Master CAM, Solid Works, etc, then you should be able to very quickly figure out Easel.
