In order for your copy of Easel to be configured to use with our X-Carve machine, if must be opened on the computer that is controlling our X-Carve machine.  Configuring the driver is a not a straight forward task and will be done by the checkout supervisor as part of your certification to use the machine.  Any setting that you might have somehow added on your own will be replaced at this time.  Since this process is only done once, it isn't importnat that you invest the time to learn it.
