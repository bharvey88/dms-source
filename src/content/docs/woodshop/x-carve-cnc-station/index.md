## How you become authorized to use the X-Carve CNC

This process is being kept simple, but since we select to have a lot of users a bit of structure is required.

1.  Create your Easel account to access the free software.
2.  Go through the various tutorials listed below
3.  Take a couple of Make-and-Take classes or the Becoming familiar with X-Carve class(coming soon).
4.  Take a short quiz on Moodle to verify you understand the basics.
5.  Create the simple test cut file you will receive after you pass the quiz.
6.  Set a day and time with one of the X-carve coach/tester folks.
7.  Demonstrate you can run your simple job and then you are set to go.

This simple process will help us verify members have both some knowledge and a small investment in the machine.

## Session Limits

Members are limited to 1 hour sessions during peak usage times(people are waiting).  If you have a complex job(2+ hours) then run it during off the off hours 10PM - 9AM.  Pleading ignorance of the job's run times isn't acceptable since it is shown at the bottom of the preview.  This rule will be enforced when people are waiting in the queue.  If you are careful, you should be able to remove your job from the machine and return later and continue running the tool paths.
