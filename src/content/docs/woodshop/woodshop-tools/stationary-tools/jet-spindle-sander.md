The spindle sander is used to sand internal radii (external radii should be sanded on the horizontal or vertical sanders).

- Select a spindle that is slightly smaller than the curve to be sanded.
- Make sure spindle is properly secured on the main shaft.
- Use table insert that has the smallest opening possible without contacting the sanding sleeve.
- Turn on sander and allow it to reach full speed before starting work.
- Hold workpiece firmly against the table at all times.
- For best results, keep the workpiece moving against the spindle.
- Make sure to use the erasers to pull the sawdust from the spindle and increase the life of the sandpaper.
