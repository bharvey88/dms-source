**Scheduling a class**

Woodshop does have certain days set aside for events or core classes.  Please discuss your plans with the Woodshop Chair prior to listing the class.



**Event Calendar**

All events and classes are scheduled via the Calendar system.  If you have never used this resource, please send a message to **@dryad2b** on Talk to get started.



**Teaching Woodshop Safety & Orientation**

Thee classes follow a set syllabus, but do allow for the teacher to add tips as they teach the class.  The goal is for all students to have a consistent experience and common information upon the conclusion of the class.

The process to begin teaching this class is straight forward.  As a prospective teacher you are required to follow one of the teachers that has taught at least 10 classes, or another teacher at the discretion of the woodshop chairs.  After monitoring the class, you will required to be checked out, i.e. a sign-off teacher will follow you as you teach a first class.    If there are any issues, you might be asked to repeat this process.  This is rare, but could occur.

Please contact the Woodshop Chair for more information
