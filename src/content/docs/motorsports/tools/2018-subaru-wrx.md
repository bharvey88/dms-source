## 2018 Subaru WRX 2.0L CVT Premium



**Trim:**  WRX mid+L+M/R

**Drive Type:**  AWD/All-Wheel Drive

**Cylinders:**  4

**Engine Model:**  DIB

**Engine Brake (HP):**  268

**Transmission Style:**  Continuously Variable Transmission (CVT)

**Engine Displacement (L):**  2



It's blue, it was donated.



## CVT:

transmission: TR690 Cvt

make sure it doesn't overheat past say 230F - monitor using Cobb port do-hickey.

it has a heater-delete so make sure it warms up before use

No hard launches



Sport \# is the setting of choice (gives it 8 pretend gears)

## CVT Fluid:

take a clean container to a subaru dealer and get some - only use subaru fluid or the the CVT will experience a texas chainsaw massacre.



## Events conquered:

G2 Motorsports Track Day 8/23/25

Must use wooden paint protectors (pictured with hot glue below)
