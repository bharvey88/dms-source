The DMS Member profile system is available to active members at <https://members.dallasmakerspace.org> and you can manage and view the following items:

## Talk (discourse)

Edit your profile to link your DMS account with your [Talk ](https://source.dallasmakerspace.org/pages/viewpage.action?pageId=2162760)handle to enable Members-Only (aka "green dot") privileges.  If you are linked via the profile system and active you will have a flair on your profile picture of our DMS logo on a light green background.  If you are still using the old system you will have only a green dot up to September 20th when the old green dots will be removed and all users will need to use the profile system from that point forward.

You will be able to view some public and private information that we have on file for you as well as any current membership linkages to Talk and your voting rights status.
