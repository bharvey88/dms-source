### Included Accessories

- 12-pt Single-Line Type Sticks, 2 inch (qty: 2)
- 12-pt Single-Line Type Sticks, 3 inch (qty: 2)
- Pencil Attachment Guide (guide for stamping text onto cylindrical items like pencils).
- Napkin Guides

12-pt font letter height is approximately 2.4mm. *Block* letter width varies depending on individual letters, but typically 2-4mm (the block is slightly wider than the actual letter).

*We don't appear to have any 18-pt Type Sticks or 72-pt Type Sticks (commonly used for larger logos).*
