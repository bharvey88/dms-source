Learn how to use basic laboratory equipment.  Learn how to wash glassware, make solutions of a given molarity or molality, weigh solids and liquids, how to set up glassware, filter liquids, use syringes, transfer liquids, use pipettes (glass and micropipettes), cannulation, and more basic techniques.  Hands-on class with a practical at the end.
