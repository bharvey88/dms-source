The Radioactivity class covers the various types of radiation as well as a hands on demonstration of using a Geiger counter of some radioactive materials.  This class is currently being updated and is intended to include a cloud chamber where you can visualize the radiation emitted as it interacts with a cloud of solvent vapors.
