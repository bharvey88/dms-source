A screen printing press is a machine used by professional printers to print multiple copies of the screen design on garments in an efficient manner. The machine will be based on the following design: [Four Color Screen Printing Press Plans](http://www.printingplans.com/screenpressplans.pdf)

<img src="/dms-source/files/mw/thumb_3_36_Photo.jpg_300px-Photo.jpg" width="300" height="224" /> Screen printing machine built by [Emily Owen](http://emilyowenartist.wordpress.com/)

## Progress

- **\[01/09/12\]** Paul Brown purchased the following "B. Full Hardware Kit" from: [Hardware Kit Store](http://www.printingplans.com/hardware.html)
- **\[2014\]** The MakerSpace purchased a 4 station press.
