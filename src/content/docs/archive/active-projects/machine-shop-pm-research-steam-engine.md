## Machine Shop Group Project: Build a model steam engine

<img src="/dms-source/files/mw/thumb_d_da_STEAM-ENGINE-3A.jpg_480px-STEAM-ENGINE-3A.jpg" width="480" height="409" alt="STEAM-ENGINE-3A.jpg" />

### Introduction

Want to know what all the equipment in the machine shop is used for? Got a project in mind but don't know how to achieve it? Come join us as we machine and assemble a model steam engine. What will you learn? We don't know, but it will be educational. :) Come and watch and/or participate. Meet up in the machine shop area.

### About

- This page documents the progress on the group project to machine and assemble a PM Research Model \#3 Steam Engine\
