## Bridgeport Series 1 Motor Information

The motor is currently wired for low-voltage operation (T1+T7, T2+T8, T3+T9, T6+T5+T4). This will allow the motor to run off of 200V-230V.

Here's a wiring diagram from U.S Motors <http://www.usmotors.com/TechDocs/ProFacts/Typical-3ph-Connections/Star-Y.aspx>\
